Privacy Policy – YT Analyst

Last updated: October 18, 2026

What the app accesses

With the channel owner's permission (Google OAuth), YT Analyst requests read-only access to:

  • youtube.readonly – the owner's channel and video information (titles, publish dates, public view/like/comment counts)
  • yt-analytics.readonly – the owner's channel analytics reports (views, watch time, average view percentage, subscribers gained, traffic sources, audience demographics in aggregate)

How data is used and stored

Data is used only to produce statistics and a dashboard for the channel owner. All data and access tokens are stored locally on the owner's own computer. Nothing is sold, shared with third parties, or used for advertising. The app cannot modify, upload or delete any content.

Google API Services User Data Policy

YT Analyst's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access / deleting data

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the app's folder on the owner's computer removes all stored data.
